# MITRE ATT&CK Technique Mapping & Shortlist (CDL-DET-V2)

## Overview
This document shortlists candidate MITRE ATT&CK techniques covered across our security log datasets (Mordor Mimikatz Dataset and Sysmon EVTX Logs).

---

## Shortlisted Candidate Techniques

### 1. T1003.001 - OS Credential Dumping: LSASS Memory
- **Tactic:** Credential Access
- **Description:** Adversaries attempt to access credentials stored in the Local Security Authority Subsystem Service (LSASS) process memory.
- **Target Dataset:** `data/empire_mimikatz_logonpasswords_2020-08-07103224.json`
- **Detection Indicator:** Process access/read events targeting `lsass.exe` (e.g., Mimikatz execution).

### 2. T1059.001 - Command and Scripting Interpreter: PowerShell
- **Tactic:** Execution
- **Description:** Adversaries misuse PowerShell to execute commands, scripts, and download malicious payloads.
- **Target Dataset:** `data/empire_mimikatz_logonpasswords_2020-08-07103224.json`
- **Detection Indicator:** Windows Event ID 4104 (Script Block Logging) or Sysmon Event ID 1 executing encoded PowerShell commands.

### 3. T1078 - Valid Accounts
- **Tactic:** Defense Evasion, Persistence, PrivEsc, Initial Access
- **Description:** Adversaries obtain and use credentials of existing accounts to gain access and maintain persistence.
- **Target Dataset:** Both Mordor JSON and Sysmon logs
- **Detection Indicator:** Abnormal logon events (Event ID 4624/4625) or unusual authentication sources.

### 4. T1021.002 - Remote Services: SMB/Windows Admin Shares
- **Tactic:** Lateral Movement
- **Description:** Adversaries leverage SMB and Administrative Shares (C$, ADMIN$) to move laterally inside the network.
- **Target Dataset:** `data/empire_mimikatz_logonpasswords_2020-08-07103224.json`
- **Detection Indicator:** PsExec execution or service creation over SMB (Event ID 7045 / Sysmon ID 1).

### 5. T1041 - Exfiltration Over C2 Channel
- **Tactic:** Exfiltration
- **Description:** Adversaries steal data by transferring it over an existing Command and Control (C2) channel or file protocol.
- **Target Dataset:** `data/exec_sysmon_1_ftp.evtx`
- **Detection Indicator:** FTP client execution (`ftp.exe`) transferring files externally.

### 6. T1059.003 - Command and Scripting Interpreter: Windows Command Shell
- **Tactic:** Execution
- **Description:** Adversaries execute commands using `cmd.exe` to run utility scripts or system commands.
- **Target Dataset:** `data/exec_sysmon_1_ftp.evtx`
- **Detection Indicator:** `cmd.exe` spawned as a child process with suspicious arguments.

### 7. T1543.003 - Create or Modify System Process: Windows Service
- **Tactic:** Persistence, Privilege Escalation
- **Description:** Adversaries create or modify Windows services to execute malicious commands repeatedly or with elevated privileges.
- **Target Dataset:** `data/empire_mimikatz_logonpasswords_2020-08-07103224.json`
- **Detection Indicator:** Event ID 7045 (A service was installed in the system).

### 8. T1110 - Brute Force
- **Tactic:** Credential Access
- **Description:** Adversaries use systematic guessing or automated dictionary attacks to gain valid account credentials.
- **Target Dataset:** `data/exec_sysmon_1_ftp.evtx`
- **Detection Indicator:** Rapid sequence of failed authentication attempts (Event ID 4625 / FTP logon failures).

## Week 2 Target Techniques & Justifications (5 Selected Techniques)

### 1. T1003.001 - OS Credential Dumping: LSASS Memory
- **Target Dataset:** `data/empire_mimikatz_logonpasswords_2020-08-07103224.json`
- **Justification:** Credential dumping is a primary objective for attackers following initial compromise to gain administrative privileges. The selected Mordor dataset contains explicit telemetry generated by Mimikatz memory read operations against `lsass.exe`, making it ideal for testing process access detections.

### 2. T1059.001 - Command and Scripting Interpreter: PowerShell
- **Target Dataset:** `data/empire_mimikatz_logonpasswords_2020-08-07103224.json`
- **Justification:** PowerShell is heavily leveraged by living-off-the-land attackers and post-exploitation frameworks like PowerShell Empire. The dataset includes script block logs and encoded command executions that allow us to build detections around malicious script usage.

### 3. T1021.002 - Remote Services: SMB/Windows Admin Shares
- **Target Dataset:** `data/empire_mimikatz_logonpasswords_2020-08-07103224.json`
- **Justification:** Lateral movement via SMB and admin shares (e.g., PsExec) is a critical phase in enterprise network compromise. The Mordor logs capture remote service creation (Event ID 7045) and IPC$ share connections, providing clear telemetry to build correlation rules.

### 4. T1041 - Exfiltration Over C2 Channel
- **Target Dataset:** `data/exec_sysmon_1_ftp.evtx`
- **Justification:** Data exfiltration represents the final impact stage of many attack cycles. The `exec_sysmon_1_ftp.evtx` log file records command-line execution and network connection events for CLI FTP utilities (`ftp.exe`), making it suitable for identifying unauthorized data transfers.

### 5. T1078 - Valid Accounts
- **Target Dataset:** Both Mordor JSON and Sysmon EVTX datasets
- **Justification:** Compromised credentials are used across multiple attack stages to blend in with legitimate traffic and bypass perimeter defenses. Both datasets contain Windows authentication events (Event IDs 4624/4625) and logon session data needed to detect anomalous account access.
